Members: Agastya Nath · Y. Rahul Dev Reddy · Paritosh Lahre · Varun Rao

### 1. Do Comments Still Tell the Truth?
- **Idea:** Given a code change and the comment above it, predict whether the comment is now wrong.
- **Question:** Does training on artificially generated mismatches carry over to real ones?
- **Data:** Panthaplackel et al. (AAAI 2021) dataset of real Java inconsistencies, plus CodeSearchNet for synthetic mismatches.

### 2. From Scorecard to Story
- **Idea:** Turn ball-by-ball cricket data into commentary, with a checker that verifies every fact.
- **Question:** Does planning what to say before saying it reduce factual errors?
- **Data:** Cricsheet. It has no commentary text, so the team builds the reference text.

### 3. Ask, Don't Guess
- **Idea:** Generate several candidate regexes, find a string they disagree on, and ask the user whether it should match.
- **Question:** How many questions does it take to reach the intended regex?
- **Data:** NL-RX and KB13 (Deep Regex repository), StructuredRegex.

### 4. When the Law Changes
- **Idea:** Models trained on IPC labels meet the new BNS code. Compare ways to adapt them.
- **Question:** Which approach handles renumbered, merged, split and new sections best?
- **Data:** ILSI / IL-TUR, the IPC↔BNS mapping table, and a small hand-labelled BNS test set.

### 5. Who's the Doctor?
- **Idea:** Hindi verbs must agree in gender. Check whether translators follow context or stereotypes.
- **Question:** Can re-ranking translations with a coreference model reduce bias without hurting quality?
- **Data:** WinoMT, FLORES-200.

### 6. Parse What You've Never Seen
- **Idea:** Split each raw log line into its fixed template and its variables.
- **Question:** Which methods work on unseen systems, and how many labelled lines does a new system need?
- **Data:** Loghub-2.0 / Loghub-2k.

### 7. Did the Minister Answer?
- **Idea:** Label each part of a parliamentary question as answered, partially answered, or not answered.
- **Question:** Does transfer from an English evasion dataset work on Indian parliamentary answers?
- **Data:** Lok Sabha Q&A archives, QEvasion, and about 500 self-labelled pairs.

### 8. Near Hanuman Mandir
- **Idea:** Tag the house, landmark, locality, city and PIN in messy addresses, then standardize them.
- **Question:** How well does training on synthetic messy addresses work on real ones?
- **Data:** OpenStreetMap India, the India Post PIN directory, and a synthetic noise generator.

### 9. Unmangling JavaScript
- **Idea:** Predict the original variable names in minified JavaScript.
- **Question:** Do models understand how a variable is used, or just memorize common names?
- **Data:** Self-generated by minifying open-source JavaScript with Terser.
